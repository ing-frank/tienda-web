# Nuevo Mundo · Tienda de Ropa y Accesorios

Página web informativa de una tienda ficticia de ropa y accesorios.
Asignatura: **Programación de Aplicaciones Web I** · Unidad: HTML y CSS · UFHEC.

## Estructura

```
/
├── index.html      Estructura de la página (HTML)
├── estilos.css     Estilos (CSS externo)
└── img/
    └── portada.svg Imagen principal (ilustración propia)
```

## Contenido

| Requisito | Dónde está |
| --- | --- |
| Encabezado con nombre y eslogan | `<header>` y sección `#inicio` |
| Imagen principal (`img`) | `img/portada.svg` en la portada |
| Lista no ordenada (mínimo 5) | `<ul class="categorias">`, 6 categorías |
| Tabla de productos (mínimo 5) | `<table class="tabla-productos">`, 6 productos |
| Promociones / información | Sección `#promociones` |
| Pie de página | `<footer>`: dirección, teléfono, redes sociales y año |
| Enlaces (`a`) | Menú, botón, teléfono, correo y redes sociales |

Sin JavaScript ni plantillas descargadas.

## Cómo verla

Abrir `index.html` en el navegador.
